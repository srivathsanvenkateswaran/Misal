Option A
Import a statement

CAMS / KFintech CAS PDF, NSDL or CDSL holding statement, broker tradebook CSV, exchange ledger CSV. A statement with transactions gives full history; a holdings-only file gives a snapshot.

Option B
Connect via read-only API key

Zerodha Kite, CoinDCX, WazirX. The key is stored in the OS keychain on this machine and is never transmitted anywhere except to the exchange. Withdrawal-enabled keys are rejected.

No sign-in, no account, no sync. Misal reads files and read-only keys, and writes one SQLite database on this machine.
