Add an account

Two ways in
CASpdf/csv
Import a statement CAMS / KFin consolidated statement (PDF, password-protected is fine), Zerodha or Groww CSV, E*TRADE stock-plan PDF.
DCXapi key
Connect an exchange Paste a read-only API key. Misal refuses keys with trade or withdraw permission. Keys are stored in the OS keychain, never in the ledger file.
