Misal — visual direction C · “Layered”

The dish is not one thing: usal, kat, farsan, onion, coriander, pav — each cooked apart, assembled into one bowl. A portfolio is the same shape. So the dashboard hero is one vertical stack of labelled strata: it is the net-worth figure, the allocation chart and the product’s namesake at once. Everything else in the app is deliberately plain so that one object carries the identity. All five screens follow, stacked.

Direction C · Layered. One loud object per app: the stack. Two type roles only — a tight semibold figure scale and a small uppercase utilitarian label. Ground is roasted kraft in light, roasted umber in dark; the slab stays dark in both so the strata never change meaning. Layer colours are fixed per asset class and reused in the coverage meter, the concentration bars, the account strips, the table group rules and the instrument swatch.

Palette checked with the dataviz validator against both the slab and the light card surface: lightness band, chroma floor, CVD separation (worst adjacent ΔE 8.6 deutan / 15.1 normal-vision) and contrast all pass on the slab and the chart wells. Saffron and turmeric fall below 3:1 on the light card, so the relief rule is honoured — every stratum, bar and swatch is directly labelled and every value also appears in a table.
